# Аудит исходного проекта

Проверен исходный commit `bdf63ba6f50986c057e569425dd9bd5ca5f3a511` репозитория kekaop/ServerBootstrap.

| Заявленное поведение | Фактический код исходной версии |
|---|---|
| ZIP из GitHub/GitLab | API-запросы реализованы. HttpClient не следует редиректам; типичный GitHub zipball с 302 не устанавливается |
| Установка плагинов и конфигураций | Копируется найденный plugins; конфигурации вне plugins не применяются |
| Миры | Ищутся world, world_nether, world_the_end, копируются в работающий сервер |
| Постоянная привязка | node-profile записывается до завершения загрузки; first-install принудительно сбрасывается в onEnable |
| Безопасная распаковка | Entry name напрямую передаётся resolve; Zip Slip не блокируется |
| Корректный результат | Ошибки отдельных файлов и удаления подавляются, поэтому сообщение об успехе ненадёжно |
| Транзакция | Нет staging с проверкой, журнала, резервных копий и отката |
| Версии и целостность | SHA-256, лимиты размера, ref и установленная версия не предусмотрены |
| HTTP | Всегда включается; путь-префикс /update, JSON secret, нет проверки HTTP-метода, лимита тела и блокировки параллельных операций |
| Permission | setup-server только из консоли; отдельного permission нет |
| Самообновление | Пропускаются пути с ServerBootstrap и NodeMetrics; также защищены их JAR |
| NodeMetrics | После установки nodeName меняется отдельно от копирования, при установленном NodeMetrics |
| Java/ядро | Компиляция Java 21, Paper API 1.21.4, api-version 1.21; runServer при этом запускал 1.21 |
| Тесты | Автоматических тестов нет |

Базовая сборка исходного commit проходит на JDK 21. На установленном JDK 25 Gradle 8.8 не запускается (Unsupported class file major version 69).

Изменения совместимости описаны в MIGRATION.md. Работа с сервером по-прежнему ограничена одним привязанным профилем, поддержаны прежние шаблоны GitHub/GitLab, команда setup-server и пропуск файлов самого плагина. Скрытые ошибки копирования и небезопасная замена загруженных миров не сохраняются.
