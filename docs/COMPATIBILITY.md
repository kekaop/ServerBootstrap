# Совместимость Minecraft и Java

Плагин использует публичный Bukkit/Spigot API 1.20.1, без NMS, CraftBukkit internals, MiniMessage и прямых Adventure API. plugin.yml объявляет api-version: 1.20, а классы имеют major version 61 (Java 17). Один и тот же production-JAR предназначен для всего диапазона.

| Ветка Minecraft Java | Java для сервера | Поддержка |
|---|---|---|
| 1.20.1–1.20.4 | Java 17 или рекомендованная ядром Java 21 | Целевой диапазон; базовый API 1.20.1 |
| 1.20.5–1.20.6 | Java 21 | Целевой диапазон |
| 1.21–1.21.11 | Java 21 | Целевой диапазон |
| 26.1.x–26.2 | Java 25 для Paper | Целевой диапазон |
| 26.3 | Java 25 для Paper | Поддержка общего API; Paper-сборки на дату проверки alpha |

Дата проверки: 18 сентября 2026. [Paper рекомендует Java 21 для 1.20–1.21.11 и Java 25 для 26.1+](https://docs.papermc.io/paper/getting-started/). Java 17 — минимальный уровень байткода самого ServerBootstrap, а не обещание запустить новое ядро на Java 17.

## Что фактически проверено

Матрица запускает весь набор автоматических тестов на разных версиях **Spigot API**, то есть именно общего API, используемого плагином:

| Test API | JVM тестов | Проверки |
|---|---|---|
| 1.20.1-R0.1-SNAPSHOT | 17 | Конфигурация, источники, TLS/HTTP, архивы, транзакции, разрешения, дескриптор |
| 1.20.6-R0.1-SNAPSHOT | 21 | Тот же набор |
| 1.21.11-R0.1-SNAPSHOT | 21 | Тот же набор |
| 26.2-R0.1-SNAPSHOT | 25 | Тот же набор |
| 26.3-R0.1-SNAPSHOT | 25 | Тот же набор |

Production-код всегда компилируется против API 1.20.1; матрица меняет API тестового classpath и JVM. Результаты и число тестов — в [VERIFICATION.md](VERIFICATION.md). Это не полноценные запуски Minecraft/Paper и не доказательство поведения каждой промежуточной версии или каждого стороннего плагина.

Через [Paper Downloads Service](https://docs.papermc.io/misc/downloads-service/) подтверждены сборки Paper 1.20.1 build 196 STABLE, 1.20.6 build 151 STABLE, 1.21.11 build 132 STABLE, 26.2 build 124 STABLE и 26.3 build 16 ALPHA. Наличие сборки не означает, что она запускалась в рамках проверки.

## Ограничения

- Поддержка серверов Java Edition Paper/Spigot; Fabric, Forge, NeoForge, Bedrock и Folia не поддерживаются.
- Совместимость сторонних JAR внутри профиля с конкретной версией Minecraft проверяет администратор.
- ServerBootstrap не меняет версию ядра и не конвертирует миры.
- Для старта/остановки и перезапуска используется стандартный API; механизм повторного запуска зависит от вашего окружения.
- Для Paper 26.3 сначала проверьте отдельный стенд: alpha-ядро и API могут изменяться.
- Новые Minecraft-ветки требуют повторной проверки матрицы и пробного запуска, даже если общий API сохранился.

Инструкции для собственного пробного запуска: [TESTING.md](TESTING.md).
