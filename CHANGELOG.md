# Изменения

Русский | [English](CHANGELOG.en.md)

## 2.1.0

- Замена полных каталогов миров через служебный мир и два перезапуска, без внешних программ.
- Журнал переключения level-name, проверка session.lock текущей JVM, staging SHA-256, запрет входа игроков.
- Отложенная фиксация версии, сохранение целых прежних миров, откат после ошибок и прерывания процесса.
- Команды maintenance-status/retry/cancel; после ошибки нет автоматического цикла повторов.
- Direct-транзакции после аварии требуют offline recover: обычный onLoad не предшествует чтению главного мира.
- Тесты жизненного цикла, ошибок между переименованиями и сохранения блокировок ОС.
## 2.0.0

- Общие источники GitHub, GitLab, HTTPS, Google Drive и прямые ZIP-assets релизов.
- Версионированная конфигурация, ref, версия артефакта, SHA-256, авторизация из окружения.
- Ограничения загрузки и распаковки; безопасные пути, CRC, отказ от неоднозначных ZIP.
- Журнал изменений, резервные копии, откат, восстановление после прерванного применения.
- Версия и привязка узла коммитятся в общей транзакции.
- Глобальная блокировка операций и межпроцессная блокировка узла.
- HTTP по умолчанию выключен; Bearer header, точный метод/путь, статус операции.
- Команды install/update/check/current/status/help и совместимый setup-server.
- Отдельная offline-утилита; запрет установки в загруженные миры и при игроках онлайн.
- Совместимость через Bukkit API 1.20.1 и Java 17 bytecode, проверки API вплоть до 26.3 на Java 25.
- Документация миграции и тесты сетевых ошибок, архивов, секретов и транзакций.
